Product tile for grids: photo, tags, wishlist toggle, category, name, price and colour dots.

- Provide `name`, `price`, optional `category`, `salePrice` (shows Sale tag, red price and struck-through original), `isNew`, `colors` (hex list), `image`, `currency` prefix.
- Place in a 4-column grid on desktop with `space-6` gutters (2 columns on mobile).
- The whole card lifts with `shadow-lift` on hover; nothing else moves.
