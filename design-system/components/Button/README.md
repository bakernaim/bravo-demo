Rectangular uppercase button in four variants; one `primary` per view.

- `variant`: `primary` (gold-deep fill — Add to bag, Shop now), `outline` (gold border on light grounds), `onDark` (gold border on `espresso`), `link` (underlined text action like "See all").
- Optional `icon` (an `Icon` name) sits after the label; `size="sm"` for inline forms; `block` for full width.
- `disabled` for sold-out states — keep the label explicit ("Sold out").
